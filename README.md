## About

AsciiNicknameToBat is a lightweight console utility written in C# (.NET) that turns plain text into 3D block ASCII art and automatically generates a ready‑to‑run .bat script for Windows. It’s perfect for creating custom ASCII nicknames, decorating the terminal, or adding creative greetings to your scripts.

## Install

Prerequisites:
- Windows 10/11 OS
- .NET 11 Runtime installed on your system.

Steps:
- Go to the Releases section on the right side of this GitHub page.
- Download the latest .zip archive.
- Extract the archive to any folder of your choice.
- Open the extracted folder and double-click AsciiNicknameToBat.exe to launch the application.
